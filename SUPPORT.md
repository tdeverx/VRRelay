# Support

VRRelay is pre-release software intended for private, self-hosted deployments.

- Use GitHub Discussions for setup questions, deployment ideas, and compatibility results when enabled.
- Use the bug report template for reproducible defects.
- Use the feature request template for scoped proposals.
- Follow `SECURITY.md` for anything security-sensitive.

Before asking for help, run `npm run ci`, check `docs/implementation-status.md`, and collect redacted versions, roles, profile revision, player/platform, and relevant error codes. Never post passwords, API keys, playback URLs, join tokens, certificates, private source URLs, or unredacted logs.
